# 控制台界面

参考 [Cal.com 设计分析](https://getdesign.md/cal/design-md) 的中性色、留白和简洁导航，使用项目自己的标识与组件。

- 固定侧栏提供总览、账号、任务、用量、模型、API Key、代理槽、行为与工具、日志、设置十个入口；手机使用抽屉导航。
- 白色／深灰色背景、细边框、黑白主按钮；绿、黄、红只表示状态。
- 页面标题、指标、操作与列表形成清晰层级；详细说明放在配置项和帮助文档中。
- 所有原有操作继续使用统一事件委托；表格保持可横向滚动，优先级输入与保存状态保持可见。
- 使用系统字体、本地 SVG，无远程字体、UI 框架或品牌素材依赖。
- 面板以带 `X-Panel-Token` 的 fetch SSE 接收刷新通知；鉴权数据不放进 URL。
- 可切换浅色、深色或跟随系统；支持简体与繁体。

- 模型列表仅进入／切换渠道／手动刷新时更新，刷新保留页码、筛选和滚动位置；模型本名与别名均可点击复制，启停与别名按渠道保存。
