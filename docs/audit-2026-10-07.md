## 已完成的功能调整

- 移除 OpenCode 上游转发、模型目录、配置入口及独立账号区，保留 WorkBuddy 国内与国际出口。历史 Key 身份和用量保留，旧出口 Key 停用，明确重绑现有出口后才可启用。
- 修复停用最后一个 Key 导致关闭鉴权的问题。面板使用后端 `auth_required` 展示状态；操作者原有的显式免鉴权开关保持其语义。
- DuckDuckGo HTML/Lite 使用标准库 `HTMLParser` 解析，支持属性重排、嵌套标签和实体，正确提取真实 URL，过滤广告、重复结果，跳转 URL 只解码一次。
- HTML 异常时最多回退一次 Lite；429 不重试，明确无结果不回退，验证码和未知布局明确报错。成功缓存 120 秒、错误冷却 5 秒、容量 128，相同查询并发合并。
- 搜索与抓取共享安全传输模块，20 秒单次网络预算、2 MiB 传输/解压上限；支持独立 `WB_WEB_PROXY`，成功抓取的 URL 可用于引用标注。

具体执行路径见[网络搜索说明](research/web-search-support.md)，旧出口与密码迁移见[部署说明](integration-plan.md)。保留的 OpenCode 客户端指纹清理只用于协议兼容，不提供该上游反代。

## 原问题与修复结果

原始失败证据保留在[审计复现记录](audit-2026-10-07-evidence.json)；同一隔离复现脚本的修复后结果见[修复证据](repair-2026-10-07-evidence.json)。测试使用本机临时 HTTP 服务和合成模型响应，未访问真实账号或模型。

| 编号 | 原问题 | 当前实现与验证 |
| --- | --- | --- |
| F1 / P1 | DNS 与重定向可绕过内网访问限制 | 校验全部 DNS 地址和每次重定向，只连接已验证的公网数值 IP，保留原域名 Host、TLS SNI 和证书校验；DNS→回环与重定向→回环均不能读取目标。代理也转发数值 IP。 |
| F2 / P1 | 轮数限制只撤回工具，仍可无限调用 | 执行前强制检查轮数、总调用数及时间预算；默认 3 轮、最多 16 次调用、180 秒。预算从首次模型连接前建立并传递到后续连接与读取。配置 1 轮后仅执行 1 轮、1 次后续请求，继续调用明确失败。 |
| F3 / P2 | 非流式后续轮次丢失前轮历史 | 共享状态逐轮追加完整 assistant/tool 消息和原调用 ID；搜索→抓取的后续消息数量为 3、5，第二轮同时保留两次工具结果。流式也验证相同行为。 |
| F4 / P2 | 只记录最后一轮 Token | 每轮按实际账号记录，最终响应汇总全部已返回用量；3 + 5 + 9 在日志与响应均为 17。中途断开时保留已收到的用量，流式失败终止事件也包含当前部分用量。 |
| F5 / P2 | 混合调用丢失客户端工具 | 执行本地工具后将真实结果与客户端调用交回客户端，保留原调用 ID；不生成客户端工具结果，也不在缺少该结果时继续模型请求。流式与非流式均覆盖。 |
| R1 / P1 | 默认 admin 密码与端口公开 | 首次启动生成随机密码，只保存加盐哈希；旧默认 admin 自动更换，已有自定义密码保留。支持 `PANEL_PASSWORD` / `PANEL_PASSWORD_FILE`。Compose 默认只发布到 `127.0.0.1`。 |
| R2 / P2 | 默认部署上游 latest，不包含本地修改 | 默认 Compose 与快速部署脚本构建当前源码，使用自己的 `workbody-fhub:1.0.0`。发布工作流先运行测试，再构建并发布自己的双架构镜像。 |
| R3 / P2 | 凭据和日志进入构建上下文 | `.dockerignore` 排除 `accounts/`、`usage/`、`.env*`、凭据文件和镜像归档；账号与日志仅通过运行时卷提供。 |

网络安全实现位于 [wb_webnet.py](../wb_webnet.py)，工具会话与预算位于 [wb_webflow.py](../wb_webflow.py)，Responses 两种响应路径位于 [wb_proxy.py](../wb_proxy.py)，密码初始化位于 [wb_settings.py](../wb_settings.py)。DNS 工作槽在 libc 查询真正结束时才释放，阻止超时请求不断积累后台解析任务。流式各轮保持同一 response ID 和递增事件序号，超限返回 `response.failed`。

容器验证还发现并修复了一个启动问题：打印局域网地址时，系统 DNS 查询可能阻塞服务开始监听。现在该信息查询最多等待 1 秒，并使用后台守护线程；无外部网络时也能启动健康检查。受控停滞 DNS 回归与两个架构的隔离容器均覆盖此路径。
