# Workbody-FHUB 1.0.2 网关与账号池更新

## 修复与行为

- **生成速度**：原统计直接平均每次请求的速率，快请求会放大结果；部分协议还把角色帧或生命周期事件当作首字。现在以有效请求的总输出 Token 除以总生成时间，三个协议的流式与非流式路径均从首个内容帧计到末个内容帧。100 Token / 1 秒与 100 Token / 10 秒的平均值为 18.2 Token/s。失败、取消、缺失用量和只有一帧内容的请求不参与速度平均值；没有有效样本显示 `—`。
- **账号区域**：账号池增加国际、国内按钮，列表、OAuth 默认区域、批量启停、导出和代理分配跟随所选区域。查看账号不会修改默认 API 出口或 Key 绑定。旧账号缺少区域时只归入国际版。
- **积分汇总**：`GET /accounts/balance` 查询缓存，`POST /accounts/balance` 刷新全部账号，均要求管理鉴权。包含停用账号，返回总积分、国内与国际小计及逐账号结果。刷新失败保留已有余额，未知余额不伪装成零；返回 `complete`、`unknown_count`、`refresh_failed` 表示完整程度。不返回账号凭据或底层异常。无效缓存数值按未知处理，超出 JSON 数值范围的汇总返回 `null`。
- **免费模型公平调度**：默认打开 `pool.free_fair_pick`，在国内、国际各自的账号池中按模型轮询，游标更新受锁保护。跳过不可用账号，余额高低不会影响免费请求分配，免费请求跳过会话绑定。模型免费目录在每日积分限额关闭时也生效，已观察到零消耗的账号不会挤掉尚未尝试的免费账号。付费模型保留原有策略与会话绑定；远端已知付费价格覆盖内置免费快照。
- **HTTP 与 SOCKS5 代理**：代理槽新增独立用户名、密码，支持 `http://`、`socks5://`、`socks5h://`，并兼容 URL 中的账密。相同地址、不同凭据是独立槽位。保存、轮询、重载和测试保留认证信息。账号 API、积分请求及网页打卡 ACP 通道共用传输；搜索通过独立的 `WB_WEB_PROXY` 与账密环境变量配置。

HTTP CONNECT 的认证只发送给代理，SOCKS5 使用协议认证。HTTPS 仍验证目标域名和证书；搜索通过 SOCKS 连接已校验的公网 IP，原始 Host 与 TLS 域名保持一致。认证失败不会自动改为直连。账号公开视图遮蔽代理 URL 中的凭据，槽位凭据仍仅通过已鉴权的管理接口编辑，落盘沿用私有设置文件。

## 验证

- `python3 tests/run_all.py`：89 个套件，73 个 Python 与 16 个 JS。
- 新增速度、积分和免费公平调度回归；公平分配包括同一会话、账号冷却与停用、逐次成本学习、120 次并发选择及付费策略不变。
- 代理测试使用真实回环 HTTP/SOCKS 服务，覆盖账密认证、错误密码、特殊字符、URL 账密迁移、不同凭据槽位、本地/远端 DNS、IPv6、HTTP CONNECT、ACP、目标 TLS SNI 与证书验证配置，以及搜索固定公网 IP。
- `python3 scripts/check_account_pool_ui.py`：真实网关 HTTP、鉴权、页面事件及持久化路径；仅上游积分查询替换为合成数据。在 Firefox 桌面 1440px、手机 390px 下检查区域切换、批量操作范围、全部余额、部分失败、代理密码保存与重载，无页面异常或水平溢出。
- `python3 scripts/verify_image.py workbody-fhub:1.0.2 --revision HEAD --non-root`：两种架构均执行启动、鉴权、release 源码哈希、11 个关键回归套件和 UID 1000 检查。镜像结果及发布证据附于 Release。

## 部署与验证边界

Compose 继续从云端拉取固定版本 `1.0.2`，监听映射保持 `0.0.0.0:8788:8788`，默认 UID/GID 保持 `0:0`，原项目声明与两份许可证保留。更新命令为 `docker compose pull`、`docker compose up -d`。

本次使用合成账号、回环代理和模拟上游，不涉及生产账号调用或生产重启。历史日志按已有耗时重新汇总，旧日志误记的首字时间无法恢复。SOCKS5 可让代理解析模型域名；网络搜索仍须由网关解析并校验目标公网 IP。HTTPS 代理的 TLS 嵌套通道没有新增支持，HTTPS 目标应使用 HTTP CONNECT 或 SOCKS5 代理。
